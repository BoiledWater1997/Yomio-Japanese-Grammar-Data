# Yomio Japanese Grammar Data

This repository contains Japanese grammar data used by Yomio.

## Source and Attribution

This dataset is adapted from the Hanabira.org Japanese Content repository:

- https://github.com/tristcoil/hanabira.org-japanese-content
- https://hanabira.org

The upstream Hanabira repository describes its content as being under a “Creative Commons License” and states that users of the content should link to hanabira.org.

Hanabira.org is credited as the source of the original Japanese grammar content.

## Changes Made

This repository contains a modified version of the original Hanabira grammar data.

Changes include:

- Cleaning and normalizing the JSON structure
- Merging duplicate grammar entries
- Converting the data into an app-specific schema
- Adding Simplified Chinese translations
- Adding Traditional Chinese translations

Changes have been made to the original content.
